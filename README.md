# 🐄 MilkTrack – Smart Dairy Management System

**MilkTrack** is a smart and efficient dairy farm management system designed to streamline milk tracking, cow health monitoring, and overall dairy operations. Built for both rural and modern dairy needs, it offers real-time data, performance analytics, and seamless user experience for farmers and admins alike.

---

## 🌟 Features

- 📊 Daily, Weekly & Monthly Milk Tracking  
- 🐮 Cow-wise Production & Health Monitoring  
- ✅ Goal Tracking and Productivity Reviews  
- 📥 PDF & Data Export of Reports  
- 🔒 User & Admin Authentication  
- 📈 Advanced Charts and Visual Insights  
- 🌐 Fully Responsive UI for all devices

## 🧰 Tech Stack

**Frontend**  
- React.js + Vite  
- Tailwind CSS  
- Chart.js & React Icons  
- Axios, ShadCN Components  

**Backend**  
- Node.js + Express.js  
- MongoDB  
- JWT Authentication  
- Multer for file uploads
